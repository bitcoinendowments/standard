# examples

One fully worked deployment, for reading rather than copying.

`lighthouse/` is a fictional endowment. It exists to test whether BES 0001 is specific enough to build a real constitution on, and to show what a filled template looks like when every placeholder has been decided. The organization does not exist and no funds are held anywhere.

**Read it. Do not adopt it.** Every number in it is a choice made for a fictional situation. Copying them wholesale is how a profile turns into an unexamined requirement, which is the failure mode the README warns about. Start from `../templates/` instead, and use this to see what a finished answer looks like.
