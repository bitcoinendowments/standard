# proposals

Every substantive change to the standard goes through a numbered proposal here. Editorial fixes and clarifications do not. See `../CONTRIBUTING.md` for which lane a change belongs in.

Copy `0000_template.md`, take the next unused number, and open a pull request. The comment period is at least thirty days.

Proposals are permanent. A rejected proposal stays in the folder with the decision and the reasoning recorded in it, because the argument against a change is as useful to a future reader as the argument for one. Dissent is recorded, never deleted.
