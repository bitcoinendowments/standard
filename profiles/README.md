# profiles

A profile is an opinionated starting configuration for a common situation. **Nothing in this folder is a requirement.** The requirements are in `../spec/`. A deployment that uses no profile at all, or writes its own, is not less conformant for it.

Profiles exist because BES 0001 deliberately leaves numbers open, and a group starting from a blank page tends to either copy the first number they see or argue for a month. A profile is a defensible starting point that states what it costs.

| Profile | Suited to |
|---------|-----------|
| `profile_standard_five_guardian.md` | An organization with five independent guardians and a treasury large enough to justify the coordination cost |

**What does not belong here.** Requirements, and anything an adopter edits in place. Requirements go in `../spec/`. Editable documents go in `../templates/`.
